# گالری طلای رضایی

وب‌سایت فارسی و راست‌چین گالری طلای رضایی، با کاتالوگ محصولات، جزئیات قیمت‌گذاری شفاف، سبد خرید، علاقه‌مندی‌ها و فرایند ثبت سفارش نمایشی.

## قابلیت‌ها

- طراحی واکنش‌گرا برای موبایل و دسکتاپ
- صفحهٔ جزئیات محصول با گالری، بزرگ‌نمایی، تب‌های اطلاعاتی و محصولات مرتبط
- محاسبهٔ قابل تنظیم قیمت طلا، اجرت، سود و مالیات
- سبد خرید و علاقه‌مندی‌های پایدار در مرورگر
- تصاویر محصول محلی و بهینه برای بارگذاری سریع
- رابط کاربری RTL با Vazirmatn

## فناوری‌ها

- React + TypeScript
- TanStack Start و TanStack Router
- Tailwind CSS v4
- Zustand
- Vite

## اجرای محلی

پیش‌نیاز: Node.js 20 یا بالاتر.

```bash
npm ci
npm run dev
```

برای ساخت نسخهٔ تولید:

```bash
npm run build
```

## تنظیم اطلاعات گالری

شماره تماس، نشانی، شبکه‌های اجتماعی، تنظیمات ارسال و نرخ نمایشی طلا در فایل زیر متمرکز شده‌اند:

`src/lib/site-config.ts`

> تصاویر صرفاً برای نمایش نمونه هستند و نشان‌دهندهٔ موجودی واقعی گالری نیستند. اعتبار منابع تصاویر در `public/images/CREDITS.md` ثبت شده است.

## انتشار

خروجی تولید پروژه در `.output/` ساخته می‌شود. تنظیم وب‌سرور باید تمام مسیرهای برنامه را به سرویس Node پروژه هدایت کند و فایل‌های استاتیک را با کش بلندمدت ارائه دهد.
